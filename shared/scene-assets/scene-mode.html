DeskBuddy — scene mode (button switches card ⇄ scene)

A button (bottom-right corner + right-click menu item) swaps the data card for a full-card pixel scene. Same two states as today: working (Generating/Prompting) vs idle (Idle/Down → idle scene with a red corner tick for Down). Scenes are drawn on a small integer grid, so the exact same bitmap fits the device screen — each concept shows a 128×64 "device" render.

References from the web: Star Office UI (pixel character changes activity with agent status), RunCat/zoomies (menu-bar pet: rests when calm, sprints under load), and the "pixel pet" rule of thumb — spend the animation budget on the idle loop, that's the state you see 90% of the time. Note on Mario: shipped apps shouldn't embed Nintendo sprites (copyright), so concept 1 uses an original "plumber" character in the same palette instead.
